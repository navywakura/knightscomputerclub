# Profile themes (fondos HD)

Reemplazá estos archivos con tus propias fotos HD **manteniendo el mismo nombre**:

| Archivo | Uso |
|---------|-----|
| `{theme}-bg.jpg` | Fondo de página del perfil |
| `{theme}-banner.jpg` | Banner por defecto (si no hay banner VIP) |
| `{theme}-preview.jpg` | Miniatura en settings |
| `decor/*` | Decoraciones laterales |

Temas: `matrix`, `meadow`, `galaxy`, `flowers`, `anime`, `ocean`, `sunset`.

Stock inicial: Unsplash (reemplazable sin tocar código).
